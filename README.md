# 투자자문 워크벤치

알스퀘어 투자자문(Capital Markets) 신입을 위한 업무 워크벤치. 정적 페이지 + Vercel 서버 함수 2개, 외부 의존성 없음.

## 구성

| # | 섹션 | 기능 |
|---|---|---|
| 01 | 모닝 브리프 | 기준금리·국고채 3/10년·CD 91일·원/달러, 캡레이트 스프레드, 딜 시그널 Top 5, 사수 한마디, 일일 루틴 |
| 02 | 딜 뉴스룸 | 6개 카테고리 7일 뉴스 취합, 우협·입찰·매각 자동 태깅, 클립 메모 → 팀 공유용 텍스트 복사 |
| 03 | 언더라이팅 | 레버리지 IRR(민감도 히트맵), 직접환원·내재 캡 역산, NOC·실질임대료·환산보증금, ㎡↔평 |
| 04 | 렌트롤 분석 | 엑셀 붙여넣기 → WALE(임대료/면적), 점유율, 만기 프로파일, 집중도, 자동 코멘트 |
| 05 | 딜 프로세스 | 소싱→클로징→사후관리 9단계: 산출물·신입 업무·흔한 실수·시험 연결 |
| 06 | 90일 로드맵 | 20개 체크리스트, 진행률 저장 |
| 07 | 용어·시험 연결 | 40개 용어 ↔ 공인중개사·감정평가사 과목/법령 매핑, 검색·필터 |
| 08 | 리소스 | 공공 데이터 소스, 엑셀 모델링 함수·단축키 |

## 데이터

- `GET /api/news` — Google 뉴스 RSS 검색 결과를 서버에서 취합(15분 엣지 캐시). 실패 시 화면은 검색 바로가기로 대체.
- `GET /api/macro` — 한국은행 ECOS. Vercel 환경변수 `ECOS_API_KEY` 설정 시 자동, 미설정 시 수동 입력 모드.
  - 기본 계열: `722Y001/0101000`(기준금리), `817Y002/010200000`(국고채 3년), `817Y002/010210000`(국고채 10년), `817Y002/010502000`(CD 91일), `731Y001/0000001`(원/달러). 코드 변경 시 `ECOS_SERIES`(JSON)로 덮어쓴다.
- 입력값·체크·클립은 브라우저 `localStorage`에만 저장된다.

## 배포

Vercel에서 이 저장소를 Import → Framework: Other → 그대로 배포. ECOS 키는 Project Settings → Environment Variables.

로컬 미리보기는 `npx vercel dev` (서버 함수 포함). 정적 서버로 열면 뉴스·금리는 폴백 모드로 동작한다.

## 주의

계산기·렌트롤 기본값은 가상 예시다. 법령 요약은 학습용이며 적용 전 국가법령정보센터 원문을 확인한다.
